# console-v2(候选版,未上线)

按《部署与运维手册》重写的一版控制台。单文件、无构建,后端同样是
Supabase(`profiles` + `records`)。

和线上版的功能差异见仓库根目录 README。简单说:这版有**收款明细统计、
CSV 导出、records 分页**,但没有线上版的**投放方案库(briefs)和概览页**。

- `index.html` — 47,818 字节
- `config.js` — 占位符,真密钥只写在服务器上

## 验证情况

用一个假的 Supabase 客户端(内存库 + 相同 API 表面)跑 Playwright 端到端测试,
48 项检查:登录、角色、五个模块增改删、下拉联动、搜索、统计数字、备份 JSON
内容、CSV 编码、member 权限、手机宽度。终版连跑 9 轮全绿。

**没有连过真的 Supabase 跑过。** 真要上线,先在一个测试项目里走一遍。
